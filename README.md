# MSc Dissertation Project

This repository contains the experiments conducted for the MSc dissertation:

**Noise-Adaptive Parameter Selection for Edge-Preserving Image Denoising**

## Project Structure

- `data/` contains the images used in the experiments.
  - `background_research_examples/` contains images used for the examples in Chapter 2.
  - `calibration/` contains the calibration images.
  - `test/` contains the test images.

- `notebooks/` contains the Jupyter notebooks used for the experiments described in the corresponding dissertation chapters.
  - `Chapter2_*` notebooks generate the background-research examples.
  - `Chapter4_*` notebooks contain the noise-estimation and parameter-calibration experiments.
  - `Chapter5_*` notebooks contain the final evaluation and comparison experiments.
  - `Load_data.ipynb` prepares and separates the image data used by the experiments.

- `src/` contains the shared Python code used by the notebooks.
  - `denoisers.py` implements the four edge-preserving denoising methods.
  - `denoising_config.py` stores the common experimental settings and calibrated parameters.
  - `metrics.py` provides the image-quality evaluation metrics.
  - `noise.py` contains the functions used to add synthetic Gaussian noise.
  - `noise_level_estimators.py` implements the tested noise-level estimation methods.
  - `utils.py` provides shared data-loading and utility functions.

- `results/` contains the figures, tables, and other outputs generated by the corresponding notebooks. Each results folder has the same name as its associated notebook.

## Notes

The notebook and results folder names indicate the dissertation chapter and experiment to which they correspond. 
The notebooks should be run from the project directory so that the relative data and results paths are resolved correctly.
